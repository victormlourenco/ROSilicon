# ROSilicon

**Play Ragnarok Online LATAM on your Apple Silicon Mac.** One window that
installs the game and runs it — no Windows, no Boot Camp, nothing to configure.

### Start here / Comece aqui / Empieza aquí

| | |
|---|---|
| 🇺🇸 **English** | [Getting Started](Getting-Started) |
| 🇧🇷 **Português (Brasil)** | [Primeiros Passos](Primeiros-Passos) |
| 🇪🇸 **Español** | [Primeros Pasos](Primeros-Pasos) |

The launcher itself speaks all three and follows whichever language your Mac is
set to.
